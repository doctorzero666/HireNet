## 任务：给 Scene 添加 🍃 树叶飘落动画

项目：/Users/zhichaojiang/Documents/HireNet/frontend/

### 从 Island 原型提取的动画代码

CSS（加到 scene.css）：
```css
.fleaf {
  position: absolute;
  top: -30px;
  animation: leaf-fall 11s linear infinite;
  opacity: 0.8;
  font-size: 20px;
  pointer-events: none;
  user-select: none;
}

@keyframes leaf-fall {
  0%   { transform: translateY(-4vh) translateX(0) rotate(0deg); }
  25%  { transform: translateY(26vh) translateX(26px) rotate(95deg); }
  50%  { transform: translateY(52vh) translateX(-14px) rotate(190deg); }
  75%  { transform: translateY(78vh) translateX(22px) rotate(280deg); }
  100% { transform: translateY(106vh) translateX(-8px) rotate(360deg); }
}
```

### 在 Scene.jsx 中添加树叶元素

在 Scene 组件中（scene__content 之前），添加 8-10 个 🍃 叶元素，每个有不同的：
- `left` 位置（分散在屏幕宽度）
- `animation-delay`（错开，避免同步）
- `font-size`（12-24px，大小不一）
- `animation-duration`（9-14s，速度快慢不一）

示例：
```jsx
{[...Array(10)].map((_, i) => (
  <span
    key={i}
    className="fleaf"
    aria-hidden="true"
    style={{
      left: `${5 + i * 10}%`,
      animationDelay: `${i * 1.2}s`,
      fontSize: `${12 + (i % 3) * 6}px`,
      animationDuration: `${9 + (i % 3) * 2.5}s`,
    }}
  >
    🍃
  </span>
))}
```
