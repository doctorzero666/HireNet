### Bug 2：求职者页 salary_range 渲染对象 Bug

API 返回 `salary_range: {max: 35000, min: 20000, unit: "元/月"}` 对象。`pickField` 返回原始对象。`salaryText` 中 `if (explicit) return explicit` 渲染 `[object Object]`，可能导致页面崩溃。

修复：salaryText 检测 salary_range 是否为对象，如果是则格式化为 "15000-25000 元/月"。
