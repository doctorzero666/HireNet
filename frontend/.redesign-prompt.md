## 任务：将 HireNet 完全改造为 Island 版设计

### 设计蓝本
island-ref.html 是从原型中提取的完整应用样式文件（55KB）。你必须严格以此为设计蓝本。

### 改造步骤

1. 先读取 island-ref.html，提取其中 :root CSS 变量和所有组件样式
2. 将 tokens-pixel.css 改为和 Island 版 :root 完全一致的 CSS 变量
3. Scene 背景改为 Island 版渐变：linear-gradient(180deg, #f8f8f0 0%, #f4f6e8 55%, #eaf2dc 100%)，底部加 hills
4. NavBar 改为毛玻璃：background rgba(255,252,244,0.92), backdrop-filter blur(8px), border 2px solid #e8dcc8, border-radius 24px
5. 卡片用 #f7f3df 非纯白色，border-radius 20px
6. 按钮按 Island 的 .btn / .btn-primary 样式：height 45px, padding 0 20px, border-radius 50px, font-weight 600, box-shadow 0 5px 0 0 #bdaea0
7. 所有 11 个页面 + 6 个组件的内联 style 逐一改为 Island 风格
8. 零像素风残留
9. npm run build 必须成功

### 约束
不改业务逻辑/路由/API/props，只改 CSS 和内联 style。
