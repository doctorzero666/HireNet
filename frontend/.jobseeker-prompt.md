设计参考：island-styles.css + 现有 Island 页面组件（Ribbon/Icon/StreamText）

### 后端 API（全部已在，无需改）

| 端点 | 用途 |
|------|------|
| GET /api/jobs | 岗位广场列表 |
| GET /api/candidates/:id/profile | 候选人资料 |
| POST /api/match-candidates | 岗位匹配候选人 |
| POST /api/candidate-match | 候选人匹配岗位 |

### 新建页面（4 页）

#### 1. `src/pages/JobSeekerHome.jsx` — 岗位广场
路由：`/jobseeker`

- Ribbon 标题 "岗位广场"
- 从 GET /api/jobs 拉取岗位列表
- 每张岗位卡片（Island card 风格）：bg #f7f3df, radius 20px, padding 20px
  - 岗位名称（weight 700）、公司名、薪资范围
  - 描述摘要（2 行截断）
  - 匹配度标签（如有）
  - 点击 → /jobseeker/job/:jobId
- 空状态：无岗位时显示 "暂无开放岗位" + 🏝️
- 顶部 NavBar（复用，需要加 jobseeker role 支持或直接用 TopNav 风格）

#### 2. `src/pages/JobDetail.jsx` — 岗位详情 + 一键投递
路由：`/jobseeker/job/:jobId`

- 岗位完整信息卡片
- "一键投递" 按钮（btn-soft pill）→ POST /api/candidate-match
- 投递后显示结果 → 跳转 ApplicationResult

#### 3. `src/pages/CandidateProfile.jsx` — 候选人资料卡
路由：`/jobseeker/profile`

- 展示 Demo 候选人资料（从 GET /api/candidates 获取）
- 技能标签列表（chip 样式）
- 经历列表
- 编辑按钮（Demo 用 alert）

#### 4. `src/pages/ApplicationResult.jsx` — 投递结果 + AI 求职信
路由：`/jobseeker/result`

- 投递成功 ✅ 提示
- AI 生成的求职信（如有，用 StreamText 展示）
- 匹配度评分
- "返回岗位广场" 按钮
