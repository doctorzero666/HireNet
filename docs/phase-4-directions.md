# Phase 4 — 网络飞轮（方向，非单元）

> **精度：方向，刻意不拆死单元。** 离得越远，写得越具体只会过时。下面是候选工作流（workstream），**不是承诺的顺序**。走到这一步时，挑一个、按 Phase 1/2 的纪律单独拆成单元、写一份真正的 spec，再开工。

---

## 命题

当注册、调用、分账、结算、声誉都能自动跑起来后，让网络开始**自我增强**：

> 贡献者越多 → 资产越多 → 调用越多 → 收益越多 → 吸引更多贡献者。

---

## 候选工作流

### W1 — 求职者 → 创作者通路

让人把经验 / 技能沉淀成可注册、可被调用、可累积版税的资产。把「求职」和「创作」两端接成一个循环——这是飞轮的进料口。
*依赖*：Phase 2 的资产注册 + Phase 3 的真实收益。

### W2 — 贡献者网络规模化（多 asset）

把「单 asset」边界打开：一次任务用多个资产、背后一长串贡献者全部被署名、被分账。这是多方分账的终极形态。
*依赖*：Phase 2 多方分账 + Phase 3 结算。

### W3 — 声誉经济

reputation 真正参与撮合与定价：成功率高 / 响应快的资产被优先调用、可要更高价。
*依赖*：Phase 3 的 reputation 数据。

### W4 — 跨境稳定币结算成为默认

跨境远程任务用稳定币结算（目标用户跨境，是甜区）；currency / chain 路由 + 法币 ↔ 稳定币桥。
*依赖*：Phase 3 结算层。

### W5 — 无头任务市场 / MCP 入口

HireNet 自身成为被外部 agent 直接调用的「任务市场无头商户」——核心形态可能是「**一个 MCP 服务器 + 一个面向人的展示页**」，而不是「一个网站 + 一个 MCP 附件」。AX（agent experience）成为一等设计目标。
*依赖*：Phase 3 的市场 + 结算。

---

## 怎么用这份文档

这一阶段**不写硬判据**。走到这里时，挑一个 workstream，把它当成一个新的「Phase 1」来对待：单独拆单元、写真正的 spec、定通过判据，再开工。在那之前，这些只是方向，不要提前精修。
