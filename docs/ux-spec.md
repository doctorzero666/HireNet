# HireNet MVP — UX 规格文档

> 历史文档：黑客松时期编写，其中的 Cobo 集成已于 2026-09 移除；现行结算方案见 README「技术架构」。

> 本文档定义 Hackathon MVP 的所有用户界面节点。每个节点含目标、信息、操作、边界。

## 全局设计原则

1. **信任透明** — AI 的每一步操作，用户都能看懂、能撤回
2. **企业效率** — 核心路径（描述需求 → 看到Agent结果）< 5 分钟
3. **渐进复杂度** — 首页 3 个元素，Dashboard 能展开 30 个指标
4. **数据安全可见** — 用户上传数据时，明确看到「数据不离开你的设备」

## 全局技术约束

- 前端：React + Tailwind CSS，组件化
- 设计系统：Open Design 选型后定制（参考 Linear/Vercel 风格 + 暖色调）
- LLM 输出：流式渲染（逐字/逐块出现，不等全部生成）
- 数据：大文件浏览器端 Web Worker 处理，只发送统计摘要
- 支付：Cobo Agentic Wallet — Pact 审批流

## 节点 0：首页

**页面**：`/`

**目标**：企业 10 秒内理解产品价值，5 秒内开始输入需求

**信息**：
- 一句话价值主张：「描述你的业务需求，AI Agent 帮你分析、执行、管理」
- 3 个可点击的示例需求（如「搭建智能客服」「分析销售数据规划明年」「开发数据看板」）
- 可选的数据上传区（折叠状态，点击展开）

**操作**：
- 输入框输入需求描述
- 点击示例需求自动填入
- 展开「附件数据」上传 CSV/Excel（可选）
- 点击「开始分析」→ 跳转节点 1

**状态**：
- 空状态：示例需求可见，输入框有 placeholder 引导
- 加载态：「开始分析」后按钮变 loading，显示「AI 正在理解你的需求...」

## 节点 0.5：本地沙箱初始化（仅上传数据时）

**页面**：内联弹层或展开区

**触发**：用户在首页上传了文件 + 点击「开始分析」

**目标**：让企业确认数据只在本地处理，建立信任

**信息**：
- 文件名、大小、行数
- 数据预览（前 5 行，脱敏）
- 安全说明列表（3 条，图标+文字）

**操作**：
- 确认并继续
- 移除文件
- 添加更多文件

**安全说明文案**：
```
🛡️ 你的数据不会离开你的设备
✓ 数据在浏览器内处理，不经过 HireNet 服务器
✓ 只向 AI 发送统计特征（分布/趋势/占比），不发送原始数据行
✓ 分析完成后，浏览器自动清除缓存
```

## 节点 1：AI 追问（流式对话）

**页面**：`/analysis/{session_id}`

**目标**：AI 问清关键信息（2-3 轮），用户感受不到「被审问」

**信息**：
- 对话气泡流式渲染
- 如果有数据上传，第一轮追问中包含数据洞察卡片
- 进度暗示（「第 2/3 轮」或「快好了」）

**操作**：
- 打字回复
- 快捷选项按钮（AI 生成的可选答案，点击即发送）

**数据洞察卡片**（如有上传数据）：
```
📊 从你的数据中初步发现：
· 2025年总销售额 $3.1M，同比增长 29%
· 增长最快品类：运动户外 (+67%)
· 退货率最高渠道：直播 (22%)
（以上分析在你的设备本地完成，原始数据未上传）
```

**追问结束条件**：AI 收集够了关键信息 → 自动过渡到节点 2

**追问过渡动画**：「信息足够了，正在生成分析报告...」→ 流式构建分析报告

## 节点 2：分析报告

**页面**：`/analysis/{session_id}#report`

**目标**：企业一眼看懂「哪些 AI 做、哪些招人、花多少钱、用谁的 Agent」

**信息**：
- 报告标题 + 生成时间
- 任务卡片列表（每个任务一张卡片）
- 每个卡片展示：任务名、执行方决策、推荐 Agent（如有）、费用预估

**每张任务卡片的三种决策状态**：

```
✅ Agent 可完成（绿色卡片）
  任务名 | Agent 可完成 · 置信度 92%
  已有 Agent：客服话术生成器（@李四）
  预估：2小时 · $60
  [▶ 启动 Agent]

⚠️ 建议招人（黄色卡片）
  任务名 | 建议招聘 · 需深度业务判断
  预估薪资范围：$15K-20K/月
  [📝 生成 JD]

🔄 人机协同（蓝色卡片）
  任务名 | 人机协同
  Agent 做前端开发 → 人做数据建模
  [查看详情]
```

**操作**：
- 勾选/取消勾选任务
- 点击「启动 Agent」→ 跳转节点 3（Pact 确认）
- 点击「生成 JD」→ 生成结构化 JD（可下载/复制）
- 底部汇总：已选任务数 + 预估总费用

**流式渲染**：分析报告不是一次性出现的——先出标题，再一张张卡片流式渲染

## 节点 3：Pact 确认

**页面**：弹层 Modal

**目标**：企业理解并批准 Agent 的消费授权

**信息**：
- Agent 名称 + 创作者
- 任务描述
- 费用明细：单价 × 预估时长 = 总限额
- 收款方信息（创作者钱包地址前6后4）
- Cobo 安全说明

**操作**：
- 确认授权 → 显示 Cobo 手机 App 确认引导（截图/动画演示）
- 调整限额（修改最大花费）
- 拒绝

**Cobo 确认流程展示**：
```
┌──────────────────────┐
│ 📱 请在 Cobo App 确认  │
│                      │
│  [App 截图示意]       │
│                      │
│ 1. 打开 Cobo Agentic │
│    Wallet App        │
│ 2. 查看 Pact 详情     │
│ 3. 确认签名          │
│                      │
│ 等待确认中...         │
└──────────────────────┘
```

**状态**：
- 等待确认：动画 + 提示文字
- 已批准 → 自动关闭 Modal，跳转节点 4
- 已拒绝 → 回到节点 2

## 节点 4：执行进度 + 结果交付

**页面**：`/execution/{task_id}`

**目标**：企业看到 Agent 在干活，结果可验收

**信息**：
- 进度条 + 当前正在做什么
- 中间产出（如有）
- 最终结果展示区

**操作**：
- 查看结果
- 下载（CSV/JSON/文本）
- 验收确认
- 追加新任务（回到节点 1，带已有业务上下文）

**完成后展示**：
```
✅ 任务完成
Agent：客服话术生成器（@李四）
耗时：1.8 小时 · 费用：$54
话术生成：120 条（售前40 + 售后50 + 投诉30）

💰 费用明细：
$54 → $37.8 创作者(@李四) + $10.8 平台 + $5.4 税费
版税记录：#RL-2026-0608-0042

[📥 下载话术表]  [👀 在线预览]  [✅ 验收确认]  [🔄 追加任务]
```

## 节点 5：企业控制台（Dashboard）

**页面**：`/dashboard`

**目标**：企业看到「我的业务被 AI 管理得怎么样」

**信息**：
- 4 个核心指标卡片（月销售额/活跃Agent数/任务完成率/本月节省人力）
- 活跃 Agent 列表（状态 + 准确率 + 本月调用次数）
- 预警区（需要关注的问题）
- 增长建议卡片

**操作**：
- 发起新业务需求 → 回到节点 0
- 点击 Agent 查看详情
- 点击预警处理问题

**MVP 简化**：Dashboard 数据用 Demo 数据展示，核心指标卡片和 Agent 列表优先做

---

## 节点 10：创作者 Agent 性能面板

**页面**：`/creator/agent/{agent_id}`

**目标**：创作者看到自己的 Agent 被调用了多少次、赚了多少钱

**信息**：
- Agent 状态（在线/离线）
- 核心指标：总调用次数、本月调用、准确率、累计收益
- 最近调用记录列表
- 收益明细（accrued / settled / total）

**操作**：
- 查看详情
- 提现（Demo 阶段展示 Cobo 结算流程）
- 编辑 Agent 配置

```
                                                    │
                                    ┌───────────────┼───────────────┐
                                    ▼               ▼               ▼
                              启动Agent(3)      生成JD(2a)     一键创建需求
                                    │
                              Pact确认(3) ← Cobo App
                                    │
                              执行进度(4)
                                    │
                              结果交付(4)
                                    │
                          ┌────────┴────────┐
                          ▼                 ▼
                     企业控制台(5)    创作者收益(10)
```
