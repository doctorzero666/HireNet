# HireNet Hackathon MVP — PRD

> 历史文档：黑客松时期编写，其中的 Cobo 集成已于 2026-09 移除；现行结算方案见 README「技术架构」。

> 版本：v1.0 | 日期：2026-06-08 | 时间盒：5 天

## 一句话

帮企业用 AI Agent 解决业务问题，创作者的知识资产获得持续收益，支付由 Cobo 安全托管，智能由智谱 GLM 驱动。

## 赞助方对齐

| 赞助方 | 我们在 Demo 中展示什么 |
|--------|----------------------|
| **Cobo** | 企业创建 Pact → 手机审批 → Agent 收款，全流程链上可查 |
| **智谱** | 所有 LLM 调用使用 GLM-4（需求分析、任务拆解、JD 生成） |

## MVP 范围

### ✅ 做

| 节点 | 页面 | 内容 |
|------|------|------|
| 0 | 首页 | 输入框 + 示例需求 + 数据上传（折叠） |
| 0.5 | 沙箱确认 | 数据安全说明 + 预览（仅上传数据时） |
| 1 | AI 追问 | 流式对话 + 快捷选项 + 数据洞察卡片 |
| 2 | 分析报告 | 任务卡片（Agent可做/招人/协同）+ Agent 匹配 + 费用 |
| 3 | Pact 确认 | Modal + Cobo App 确认引导 |
| 4 | 执行+交付 | 进度条 + 结果展示 + 费用明细 + 版税记录 |
| 5 | 企业控制台 | 4 个指标卡片 + Agent 列表 + 预警卡片（Demo 数据） |
| 10 | Agent 性能面板 | 调用次数 + 准确率 + 收益 |

### ❌ 不做

- 企业知识库/数据沉淀
- 多 Agent 协同执行（单 Agent 单任务）
- 真实文件上传处理（用 Demo 文件模拟）
- 创作者端完整注册流程（预置 2-3 个 Demo Agent）
- 求职者端任何功能
- 真实 JD 生成的多轮追问（Demo 直接出）
- Cobo 真实集成（展现代码路径 + App 截图模拟确认流程）

## Demo 脚本（3 分钟）

```
0:00-0:20  首页
  「为电商平台搭建智能客服系统」→ 点击开始

0:20-0:50  AI 追问（流式对话）
  AI 追问 2 轮 → 展示数据洞察卡片（Demo 数据）→ 自动过渡

0:50-1:20  分析报告
  3 个 Task：Agent可做 / 人机协同 / 建议招人
  匹配到「客服话术生成器」→ 费用 $60

1:20-1:50  Pact 确认 → Agent 执行
  点击启动 → Pact Modal → Cobo App 确认截图 → 执行进度条

1:50-2:20  结果交付
  120 条话术生成完成 → 费用明细 + 版税记录

2:20-2:40  企业控制台
  4 个指标卡片 + Agent 准确率列表 + 预警

2:40-3:00  价值总结
  「企业问题被 AI Agent 解决，创作者获得持续收益，
   支付由 Cobo 安全托管，智能由智谱 GLM 驱动」
```

## 技术决策

| 层 | 选择 | 理由 |
|----|------|------|
| 前端框架 | React + Vite | 组件化、快速开发 |
| CSS | Tailwind CSS | 符合 Open Design 设计系统 |
| 设计系统 | Open Design 选型 + 定制 | 142 套可选，快速出 UI |
| LLM | 智谱 GLM-4 | 赞助方要求 |
| 后端 | 现有 Flask + SQLite | 不改，只加适配 |
| 钱包 | Cobo Agentic Wallet | 赞助方要求，Pact 审批 |
| Agent 执行 | 模拟（Demo 脚本返回） | 不做真实 Agent 接入 |
| 数据上传 | Demo 跳过 | 用预置数据模拟 |
