# HireNet Demo 录制脚本

> 时长：3-4分钟 | 重点：Cobo 支付闭环 + 三端协同

---

## 第一幕：产品定位（15秒）

**画面**：首页 🍃 HireNet，三张角色卡

**旁白**：「HireNet——基于 Cobo Agentic Wallet 的 AI 劳动力网络。企业发布需求，AI Agent 自动执行，创作者获得链上收益。全程由 Cobo 安全托管支付。」

---

## 第二幕：企业端 — 发布需求（45秒）

**操作**：
1. 点击「雇主」→ 进入分流页 → 选择「发起委托」
2. 输入需求："帮我为电商平台搭建智能客服系统"
3. 点击「开始分析」→ AI 追问 2-3 轮
4. 进入分析报告 → 显示 3 个任务卡片（Agent可做/招人/协同）
5. 点击「生成 JD」→ Markdown 弹窗预览 → 「发布到岗位广场」

**亮点**：智谱 GLM-4 驱动的需求分析 + Agent 匹配

---

## 第三幕：企业端 — Cobo 支付（60秒）⭐ 核心

**操作**：
1. 在报告页，点击 Agent 任务的「启动 Agent」
2. 弹出 Pact 授权 Modal：
   - Agent 名称 + 创作者
   - 费用明细
   - 收款方钱包地址
3. 点击「确认授权」→ 跳转执行进度页
4. 进度条走完 → 任务完成
5. **费用明细展示**：$54 → $37.8 创作者 + $10.8 平台 + $5.4 税费
6. **Cobo 结算状态**：`settling` → Cobo transfer → `settled` + tx_hash

**旁白**：「关键在于支付——企业确认 Pact 后，Cobo Agentic Wallet 自动执行链上结算。创作者无需手动提现，收益直接到账，全程链上可查。」

---

## 第四幕：创作者端 — 收益到账（40秒）⭐ 核心

**操作**：
1. 返回首页 → 切换到「张AI」身份（JWT 登录 or 身份切换器）
2. 进入「我是创作者」→ Agent 工坊
3. 点击「客服话术生成器」→ 性能面板
4. **突出收益明细**：accrued → settling → settled，显示 Cobo tx_hash
5. 「已结算」状态高亮

**旁白**：「切换到创作者视角——刚才的结算已经到账。Cobo 的链上确认可溯源，每一笔收益都有 tx_hash 可查。」

---

## 第五幕：求职者端（30秒）

**操作**：
1. 切换到「王工」身份 → 岗位广场
2. 看到刚才企业发布的「全栈工程师」JD
3. 点击进入 → 一键投递
4. 「AI 分析我的优势」→ StreamText 展示分析结果

---

## 第六幕：Dashboard + 总结（20秒）

**操作**：
1. 切回企业端 → Dashboard
2. 展示 4 个指标卡片 + Agent 列表 + 预警

**旁白**：「HireNet——让企业找到 AI 劳动力，让创作者获得链上收益，让求职者发现机会。Cobo 安全托管，智谱 GLM 驱动智能。感谢观看。」
