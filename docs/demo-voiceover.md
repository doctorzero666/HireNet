# HireNet Demo 配音脚本 v2

> 总时长：~3.5 分钟 | 节奏：每页 20-25 秒

---

## 开场：问题 + 定义（25 秒）

**画面**：首页三张角色卡并排——🏢 雇主 · 🎨 创作者 · 👤 求职者

**配音**：「今天的企业招聘，三方都很痛苦——老板费尽心思写 JD，求职者海投等消息，有技能的人被困在简历格式里。这三个角色的需求，从来不在同一个系统里。」

**画面**：三张卡片合拢，Logo 🍃 HireNet 出现

**配音**：「HireNet 把三端放在一张桌子上。老板描述需求，AI 拆解任务，Agent 自动执行，求职者精准匹配。一套系统，三个视角。我们不做招聘——我们让招聘变得不需要。」

---

## 第一幕：企业端（40 秒）

**画面**：点击「我是雇主」→ 输入框

**配音**：「企业不再写 JD。用自然语言描述你想完成什么——比如：'为电商平台搭建智能客服系统'。」

**操作**：输入，点「分析」

**画面**：AI 追问对话 + 快捷选项（售前 / 售后 / 投诉 / 三者都要）

**配音**：「智谱 GLM-4 驱动的需求分析 Agent 自动追问关键信息——覆盖场景、渠道、预算。你只需要点选回答。」

**画面**：分析报告页，3 张任务卡片弹出——Agent 可做 / 需招人 / 人机协同

**配音**：「几秒钟，系统自动拆解任务并做出决策。不需要 HR、不需要写岗位描述——你描述问题，AI 给出方案。」

---

## 第二幕：Cobo 支付闭环（55 秒）⭐

**画面**：点击 Agent 任务「启动 Agent」→ Pact 弹窗

**配音**：「这里是我们最核心的一步。」

**画面**：Pact 弹窗——Agent 名称、费用明细、钱包地址、Cobo 确认

**配音**：「点击启动后，系统创建一份 Pact 授权。费用明细、创作者钱包地址、预估工时——全部透明。Cobo Agentic Wallet 自动完成链上结算。」

**操作**：点「确认授权」

**画面**：进度条 → 完成 → 费用拆分卡：$54 → $37.8 创作者 + $10.8 平台 + $5.4 税费

**配音**：「三端自动分账——创作者拿七成，平台抽两成，税费一成。交易哈希可查，资金流向完全透明。」

---

## 第三幕：创作者端（35 秒）

**画面**：切「我是创作者」→ 工坊 → 点「注册新 Agent」

**配音**：「现在看创作者端。任何人可以注册自己的 AI Agent——填写名称、描述、能力类型、定价和钱包地址。」

**画面**：注册表单 → 已注册的 Agent 列表

**配音**：「Agent 注册完成后，企业端就能搜索到并调用它。收益方式很简单——你的 Agent 被调用一次，Cobo 就自动结算一笔版税到你的钱包。」

**画面**：Agent 性能面板——调用 12 次，准确率 92%，累计收益 $1,260

**配音**：「每次调用都有记录。调用次数、准确率、累计收益——你的技能变成了一份可持续变现的数字资产。」

---

## 第四幕：求职者端（35 秒）

**画面**：切「我是求职者」→ 岗位广场

**配音**：「求职者端也不一样——不再是海投简历。」

**画面**：浏览岗位列表（全栈工程师 / AI 产品经理 / 数据分析师）

**配音**：「填写资料卡后，系统自动匹配适合的岗位。看到合适的，一键投递，不需要逐家修改简历。」

**画面**：点「我的资料」→ 技能标签 → 「AI 分析我的优势」

**配音**：「点击 AI 分析——智谱 GLM-4 读取你的技能和经历，告诉你最适合什么方向、你的核心优势在哪里。不是机器筛选你，是 AI 帮你认识自己。」

**画面**：StreamText 打字效果展示分析结果

---

## 第五幕：盈利模式 + 收尾（25 秒）

**画面**：三端循环动画——企业→Agent→创作者→企业

**配音**：「HireNet 怎么赚钱？每笔交易抽两成平台服务费。企业付 $60，平台收 $12，创作者拿 $42。Agent 越被调用，平台收益越多——这是一个自增长的飞轮。」

**画面**：Dashboard + Logo

**配音**：「老板描述需求，Agent 自动干活，创作者赚版税，求职者精准匹配。一套系统，三个视角，一个飞轮。HireNet——让 AI 替你工作，让链上替你分钱。」

---

## 录音要点

- 开场语速正常，建立信任感
- 第二幕 Cobo 是高潮，"自动分账""链上透明"加重
- 第三幕创作者端语气要兴奋——"你的技能变成数字资产"
- 第五营收尾要有力，"一个飞轮"停顿半秒再出最后一句
